# Goose on the Scale — אווז על המאזניים

A comic 3D stealth puzzle for Hebrew-speaking grade-8 students: a mischievous goose sneaks around a Jerusalem-style shuk, where every stall's two-pan scale is a linear equation. Tip the scale while the vendor is watching and you get shooed. The only safe way to mess with a scale is to do the same thing to both sides.

Work in progress. Rules and tests first; the 3D game is being built now.

```bash
npm install
npm test
npm run dev   # http://localhost:5179
```
